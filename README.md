# ROBÔ GMA

Sistema administrativo para gestão de condomínios.

## Stack
- Next.js
- TypeScript
- Tailwind CSS
- Supabase ready

## Como executar

1. Instale as dependências:
   npm install
2. Configure as variáveis de ambiente:
   cp .env.example .env.local
3. Inicie o projeto:
   npm run dev

Acesse http://localhost:3000

## Observações
- Esta primeira etapa inclui somente estrutura inicial, dados demonstrativos e navegação funcional.
- Não há envio de e-mails, mensagens ou notas fiscais neste momento.
